A prediction-market exchange for 5-minute BTC options

“Will BTC be ≥ $63,550 at 07:52 UTC?” — a market that opens, takes real orders, and settles five minutes later. The house quotes both sides, so it is the counterparty to everything, and carries genuine directional inventory risk.

The system, running

Real users, real matching, real settlement — against production order-validation, matching and payout services on a local Docker stack.

Why this is hard

An order-book exchange matches buyers to sellers and takes a fee — it holds no position. A prediction market with a house maker is a different animal: when the crowd buys YES, the house is short YES, and it owns a directional bet on Bitcoin it never chose.

Pricing
τ in seconds
Does Black–Scholes describe a binary five minutes from expiry? An empirically-calibrated curve replaced it.
Quoting
Inventory-aware
How wide, and how asymmetric, given what you already hold — Stoikov plus gamma, inventory and flow widening.
Hedging
Delta, not gamma
A linear perp cannot hedge a digital's terminal gamma. It can hedge delta, and that pays.

The market-maker desk

The operator's view, decomposed so P&L is attributable rather than a single number.

Splitting realized from quoted spread is the point. A maker that looks profitable on quoted spread can be losing steadily to informed flow, and only the difference between those two numbers reveals it.

Instrumentation, built after an incident

A market with no resting quote on one side is invisible in aggregate P&L and immediately obvious to a user trying to trade.

The tail is what matters. Typical gaps are 0.4–0.8s — one requote round-trip, unavoidable. The 24.9s outlier is a real failure, and recording it with time-to-expiry is what makes it diagnosable rather than folklore.

The only substituted component on the order path is sqs-bridge. Everything that validates, matches, settles or pays out is production code — which is the point: results measured here mean something for the real system.

Run it yourself

This page is a walkthrough, not a live deployment — the exchange is five services plus Docker, so it runs locally rather than on static hosting.

docker compose up -d              # redis · mysql8 · dynamodb-local · elasticmq · postgres
node setup/create-schema.mjs      # idempotent bootstrap
node app/server.mjs               # :5050 — also spawns the persistent quoter
node drivers/oracle-feed/index.mjs
No real money anywhere. The exchange is local and play-money; the hedge runs against the Binance demo venue, with mainnet hosts blocked in code.
